# 头部拆件 Spec 规划（捏脸系统）

> 定位：这不是「把一张画拆开拼回去」，而是**捏脸系统的可替换组件**。
> 每个部件要能独立换装、镜像、挂骨骼，head_base 是所有部件的公共底座。

## 1. 系统定位对 spec 的硬要求

| 要求 | 原因 | 对 spec 的约束 |
|------|------|----------------|
| 部件可独立替换 | 捏脸要换眼型/瞳色/发型 | 每个部件是**完整形状**，不裁切、不互相咬合 |
| 遮挡靠图层叠加 | 换装后遮挡关系不能变 | 只声明 `z`（绘制顺序），不做像素级挖洞 |
| 自动对齐 | 导入 Spine 不能手工摆位 | 所有部件共用同一套画布坐标（385 × 1672），pivot 记录画布坐标 |
| 左右可镜像 | 成对部件要能批量做变体 | 声明 `mirror` 配对，左右件形状基准一致 |
| 可挂骨骼 | 头发摆动、下颌开合、眨眼 | 每件声明 `pivot`（画布坐标） |
| 底座必须干净 | head_base 是所有部件的底，脏了整脸都脏 | 见 §4 质量门槛 |

### head_base 是这整套东西的底座，两条不可妥协的要求

1. **不带任何五官 —— 五官包括耳朵**：没有眼睛、眉毛、嘴巴、鼻子、**耳朵**，也没有头发。
   只有皮肤、颅顶、后脑、两侧、下巴、脖子。
   - 捏脸系统换脸型换的就是这一件，它上面沾了原来的五官就没法用了。
   - **耳朵必须从基底上拿掉**：耳朵是 z=1 的独立部件，会叠在基底上面；
     如果基底自己就画了耳朵，合成后脖子上会出现两只耳朵。
2. **完整**：颅顶到颈根一整块，不裁切、不挖空。五官靠 z 序叠加遮挡
   （耳 z=1、眼 z=2、眉 z=3、嘴 z=4 压在上面），**不是**在底座上挖洞。

### 耳朵只做一只

原图是 3/4 视角，另一只耳朵被头骨和头发完全挡住，没有像素，目前用不上，不做。

**头部拆件的边界只到下巴/颈根（y ≈ 485）**，锁骨以下属于身体（`torso`），不在这里。


## 3. head_base 的 bbox 怎么定（关键）

head_base 是**裸头骨**：颅顶 + 后脑 + 脸 + 脖子，**不含头发体积**。

原图里颅顶被头发盖住，看不到，所以不能用「不透明区域」直接量。用下面三个可测特征推：

| 量 | 来源 | 值 |
|----|------|-----|
| 脸宽 | 皮肤连通域（最大块） | x 172 → 328，宽 156 |
| 脸+颈 bbox | 皮肤连通域（≥5000px） | [103, 138, 330, 485] |
| 下巴 | 脸部连通域底边 | y ≈ 376 |
| 颅顶 | head 图层剪影顶 y=2 减去头发厚度（原图顶部头发约 15–20px） | y ≈ 20 |
| 颈根 | head 图层底边 | y = 485 |

**推导**：
- 左侧：耳廓左边 82 − 头骨外扩余量 ≈ **92**
- 右侧：脸右缘 330 + 颞部余量 ≈ **338**
- 上：**20**（颅顶）；下：**485**（颈根）

→ `head_base` bbox ≈ **[92, 20, 338, 485] = 246 × 465**，长宽比 1.89。

**必须满足**：head_base 的轮廓要**落在 hair 轮廓之内**（否则光头顶盖会露在头发外面）。
原图 head 图层剪影是 [5, 2, 358, 483]，即 hair 的外轮廓 —— head_base 是它的内缩版。

> ⚠️ 实测过的问题：AI 画光头时会把它画得偏宽偏矮（第 5 轮出的是 463×721，长宽比 1.56，
> 而目标是 1.89）。用统一缩放摆进去后，颅顶就冒到头发外面了。
> 所以 §4 必须把「长宽比偏差」当硬门槛卡住，超了就重生成，而不是靠后处理去裁。

## 4. 质量门槛（每轮生成后的验收线）

### head_base（最严）
| 指标 | 门槛 | 怎么量 |
|------|------|--------|
| 内部空洞 | **0 px** | `binary_fill_holes` 后减原 mask |
| 发丝/五官残留 | 非肤色像素 **< 1%** | 颜色分类（R−G>10 且 \|G−B\|<16 为肤色） |
| 长宽比偏差 | **≤ 5%**（对 1.89） | bbox w/h |
| 与目标轮廓 IoU | **≥ 0.95** | 与 [92,20,338,485] 椭圆/凸包比 |
| 完整颅顶 | 顶部有连续皮肤带，宽 ≥ 60% 头宽 | 逐行扫描 |

### 五官（eye / brow / mouth / ear）
| 指标 | 门槛 |
|------|------|
| 长宽比偏差 | ≤ 15%（对 spec bbox） |
| 完整性 | 无截断（外接框四边都留白） |
| 颜色 | 与 spec 参考区色差 MAE ≤ 25 |

### hair
| 指标 | 门槛 |
|------|------|
| 长宽比偏差 | ≤ 5% |
| 覆盖 | 能完全盖住 head_base 的颅顶区（y < 200 部分） |

## 5. 生成方案

**不用蓝图。** 最小两步：

```
1. AI 拆图      输入 = 原画头部放大到 1200×1600（输出画布 == 输入画布）
2. alpha_split  按 alpha 连通域拆件（--bg auto）
```

提示词必须显式写死这几条：
- head_base 是**完全没有五官的光头**，眼睛、眉毛、嘴巴、鼻子、**耳朵**、头发一个都不许画
- 每件都是完整形状，不裁切、不挖空
- 画风、线条粗细、平涂上色、颜色与原图完全一致
- `--remove-bg-method none`（`standard` 会把嘴巴这种小连通域当噪点删掉）

### 部件命名不要靠自动配对

AI 每轮给每件各自定尺度，所以「相对面积」和「长宽比」都**不足以**唯一识别部件
（实测：AI 的耳朵相对面积排第 3，spec 里排第 5；AI 的光头长宽比 1.617 与 spec 耳朵 1.587 几乎相同）。
直接看 `preview.png`，按阅读顺序用 `alpha_split.py --names` 手工命名一次，最省事也最可靠。

### 为什么不用蓝图（踩过的坑）

- 蓝图（把每件按真实大小预先摆好）确实钉住了尺度，但**代价是风格**：
  为了给 head_base 一个占位形状，我构造了一个椭圆胎，AI 照着描，
  结果把平面赛璐璐画成了光滑的蛋形，线稿和明暗全丢。
- **而且蓝图解决的是一个不存在的问题**：最后每件都要按 spec 归一化
  （`fit_parts --scale-mode aspect`），AI 在拆件图上用什么尺度根本不影响结果。
  唯一要紧的是每件自己的长宽比和风格。

实测对照（head_base 长宽比，目标 1.890）：

| 输入方式 | AI 出的尺寸 | 长宽比 | 偏差 | 风格 |
|----------|------------|--------|------|------|
| 原画 小画布 | 240×409 | 1.704 | 8.7% | ✅ |
| 原画 1200×1600 | 305×583 | 1.912 | **1.2%** | ✅ |
| 蓝图 v2（head 图层剪影占位） | 463×721 | 1.557 | 16.6% | ⚠️ |
| 蓝图 v3（自造椭圆胎占位） | 379×718 | 1.894 | 0.2% | ❌ 丢风格 |

→ **选「原画 + 大画布」**。

## 6. 缩放与拼合

- **统一缩放**（蓝图已把尺度钉死，`--scale-mode uniform`，实测 0 变形）
- 按 `z` 叠加
- 不做逐件拉伸（`per-part` 会让 head_base 变形 32%，五官变形更大）
- 整体锁定：拼合并集 bbox 对齐 spec 整体 bbox（`--lock-overall geom`）

## 7. 已定决策

| 问题 | 决定 |
|------|------|
| 眼睛分层 | **保持整只眼**（`eye_L` / `eye_R`），换瞳色时整眼替换 |
| 耳朵 | **只做一只**（原图可见的那只）。另一只被头骨和头发完全挡住、没有像素，目前用不上 |
| 头发分层 | **保持整块**（`hair`） |
| 嘴分层 | **保持单层**（`mouth`） |
| head_base 五官 | **必须完全没有**（不许有眼/眉/嘴/鼻/耳/发）—— 这是底座，沾了原五官就没法换脸型 |
| 生成脚手架 | **不用蓝图**，见 §5 |

→ 最终部件数 **8**。

## 8. 执行顺序

1. `prep_ai_input.py` → 1200×1600 输入
2. AI 拆图（提示词见 §5）→ `out_*/edited.png`
3. `alpha_split.py --bg auto --bg-tol 16 --min-area 60` → 8 个连通域
4. `verify_spec.py` 按 §4 卡门槛；head_base 不达标就回第 2 步重生成
5. `fit_parts.py --scale-mode aspect --lock-overall geom` → 整身画布 385×1672
6. 导入 PS 看效果

> spec 里的 `head_base.require = "no_features"` 就是给第 4 步用的标记。
