Free 3D Character Models ​

← Search this category in the asset library

Characters are the hardest asset to find for free and the one every project needs first. Every model below is a single CC0 character you can download as a GLB right here, and many arrive already rigged and animated. If one doesn't, you can put a skeleton on it in the browser and borrow motion from a CC0 library without touching Blender.

Every model here is CC0, hosted by us, and downloads as a single GLB straight from the card. No account, no signup, no attribution required. The originals are by Kay Lousberg, Quaternius, Kenney and Polygonal Mind, who deserve the credit even though the licence doesn't ask for it. To turn one over in 3D first, open it in the GLB viewer.

Choose a character with the right rig ​

Already rigged and animated? Try the included motions before paying for a new rig. A skinned skeleton means the mesh has bone weights; a node-based rig moves separate parts. An animation count alone does not tell you which kind of rig is present. Cards show the rig type when the catalogue supplies it.

Getting a free model into a browser game ​

Most of these download as GLB, glTF, FBX, or OBJ. GLB is the format the web wants, since it packs the mesh, materials, and textures into one binary file that three.js, Babylon.js, and PlayCanvas all load directly.

If your download is an FBX or OBJ, convert it to GLB in your browser. To see what's actually inside a file before you commit to it, open it in the GLB viewer, which shows the scene graph, materials, triangle count, and any animations. Before shipping, run it through the GLB optimizer to strip unused data and compress the geometry.

For characters, an unrigged mesh isn't a dead end. The auto rigger puts a skeleton on a humanoid model in a couple of minutes, and the animation library retargets 260 CC0 motions onto it without you opening Blender.

Licences, briefly ​

Every file on this page is CC0, which is public domain. Use it in a commercial game, modify it, sell the result, credit nobody. There is no attribution clause to comply with and no share-alike condition to trip over, which is why this library is CC0-only rather than a mix.

That is not true of free assets generally. Plenty of what you'll find elsewhere is CC-BY (credit required) or CC-BY-SA (credit required and your derivatives inherit the licence, which is a real constraint on a commercial game), and the licence is usually set per file rather than per site. The complete guide to game asset licences covers what each one requires and where teams usually get it wrong.

Check the model before importing ​

Each card lists available catalogue metadata. Dimensions are width × height × depth in metres; vertex counts are not triangle counts. An animation clip count means motion is embedded in the file, not that it will retarget to every skeleton. Missing metadata is left unclaimed.

Check scale, pivot and materials in the GLB viewer, then test the file in your target engine. For characters, the rigging and animation guide explains the next steps. For scenes and props, use the game asset workflow guide.
