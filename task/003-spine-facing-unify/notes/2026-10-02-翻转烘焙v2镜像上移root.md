## v1 → v2 差异

| | v1（2026-09-27 交付） | v2（2026-10-02） |
|---|---|---|
| 镜像标记位置 | root 直接子骨（hip 类骨 `scaleX=-1`） | **root 自身**（`scaleX=-1`） |
| 子骨 setup 改动 | `(x,y)→K·(x,y)`、`rotation→α−rot`、`shearX/shearY/scaleX` 取反（5 字段） | `(x,y)→M·(x,y)`、`rotation += β`（3 字段）；**shear/scale 不动** |
| 动画通道改动 | rotate→取负、translate→K 线性部、shear→取负 | **只有 translate**→M 线性部；rotate/shear 不动 |
| 数学 | K = A_r⁻¹·Fx·A_r（正交反射，det<0） | M = Fx·K = T(c)·R(2θr)（**纯旋转**，det>0） |
| root 零旋转零偏移特例 | 子骨 5 字段翻转 | **整个烘焙 = root 加 scaleX=-1，其余一字不动** |
| G 闸门 | G1/G2/G3 | 同名同阈，G3 允许面收窄（见下） |

G2 参考系不变：烘焙包逐骨世界 == Fx·原包世界（Sim 模拟官方 4.3 runtime，≤1e-6）。
root 世界矩阵 v2 起变为 A_r·Fx（镜像所在地）；root 无槽无附件，不入 G2 比较集。

v2 数学要点：子骨共轭 M 是纯旋转 ⇒ 轴角平移不混叠，shearX/shearY/scaleX/scaleY
可原样保留；rotate/translate 的 key 都是相对量，rotate 值不需要翻号（v1 翻号是因为
setup 里 rot' = α−rot 把镜像塞进了子骨自身）。

做镜像翻转的主要目的是**动作迁移时统一坐标变换与预览效果**，现有已交付包已朝向统一、

动作迁移时的形态注意点（预记）：
- 深层骨（翻转域骨的后代）：v1 源包与 v2 目标骨架的 rotate/translate/scale 轨道值
  **可直接拷贝**——两种形态下镜像域内的符号行为一致，逐骨世界矩阵等价（A/B 已验证）。
- 翻转域骨本体（hip 类）：v1 源包 setup 是「镜像塞进子骨」的共轭值（rot'=α−rot），
  v2 目标骨架是纯旋转共轭值（rot+β），两者 setup 约定不同——迁移该骨的 rotate 轨道时
  需做一次符号对齐（接 002 动画迁移时处理）。
