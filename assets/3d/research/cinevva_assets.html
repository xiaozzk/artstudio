Cinevva combines asset discovery with browser tools for preparing a model. Convert FBX or OBJ to GLB, inspect the model, reduce its size, or compress textures to KTX2. For characters, explore auto rigging and animation tools. You can also create a game using the integrated asset search.

Free game asset questions ​

Can I use these assets in a commercial game? ​

Check the license attached to the individual asset. The featured downloads above are CC0. Other search results can use attribution, share-alike, noncommercial or paid licenses. A free download does not by itself establish permission for commercial use. Keep the source URL and license with your project; the game asset license guide explains how to compare sources.

Which libraries can I search? ​

The search connects to sources including Kenney, Quaternius, KayKit, Poly Haven, ambientCG, OpenGameArt, Freesound and Sketchfab. Coverage and availability vary by source. Some sources include paid or restricted assets, so check the license on each result. The curated free categories provide a starting point for free downloads.

Are downloads hosted by Cinevva or the original creator? ​

The featured GLB files above are hosted by Cinevva and credit their original creators. Other results link to the source library, where you can confirm the current file, license and download requirements. Search results are not all original Cinevva artwork.

Which file format should I choose? ​

For browser games, GLB packages glTF model data into a single binary file. Check your engine's importer and the model's materials, scale and animation support before choosing a format. If your source is FBX or OBJ, use the GLB converter, then inspect the converted model before adding it to a scene.

Do I need an account to download assets? ​

The featured CC0 GLB files on this page download directly without a Cinevva account. External providers set their own account and download requirements. Other Cinevva tools may have separate access or usage limits.
