# 2026-10-02 —— 骨骼/插槽/附件图三类命名统一（task/005）

## 背景

09-30 的 `.spine` 工程重导出精简包（34 骨 / 26 槽 / 25 附件 / 无动画）里，骨骼已是英文语义名，
但**槽名、附件名、图片名还是旧拼音/简写混名**（`Lhand2` / `wq2` / `wb` / `Rtui3` / `no` /
`leg_l_shin.png` 等），且槽名侧别与所挂骨骼语义不对应（如 `Lhand2` 挂上臂骨、`Rtui3` 挂左小腿）。
用户拍板三类命名一次统一。

## 命名口径（用户拍板）

- **不用缩写**：`l→left`、`r→right`，`seg` 一类缩写去掉；
- **侧别放类型 token 之前**：如 `arm_l_upper → arm_upper_left`（含 `_bone` 后缀即
  `arm_upper_left_bone`；带级别后缀时侧别恰好倒数第三：
  `hair_back_drop_right_bone_1`）；
- **倒数第二位是类型**：骨骼 `_bone`、插槽 `_slot`，一眼区分；
- **最后一位是多级级别**：链式骨 `_1.._N`（`tail_bone_1..7`）。
