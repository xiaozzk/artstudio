## 关于"要不要把这些图留在仓库里"（Lead 决策，2026-10-13）

**决定：保留。** 依据：

1. **去重检测结果 = 0 重复**（按 sha256 比对这批 111 张 PNG，**没有任何两张内容相同**）→ 没有"冗余"可删。
   工作区的存储策略明确：**先去重，再谈压缩**；而通用压缩对这批数据近乎无效（实测 PNG 仅省 2%）。
2. **文档嵌了它们** —— `COMPLEXITY.md`、`FINDINGS.md`、`ACCEPTANCE.md`、`bodyshape_v2_recommendation.md` 都引用这批图，撤掉会把文档打断。
3. **它们是验证结论的审计链**：本任务的核心价值就是"每条结论都经独立复算"，把证据删掉等于**把可审计性换成 64 MB**。
4. **成本极小**：111 张 PNG + 10 份 `.blend` ≈ **64 MB**，占 LFS 免费额度（10 GiB）的 **0.6%**。
5. **全部可再生**：生成脚本均已入库（见上表与 `run_verify.sh`），但重跑要花 Blender 时间 —— 所以"可再生"不是删掉的理由，反而是**保留成本低**的理由。

> ⚠ 若要将来瘦身，**别只做 `git rm --cached`** —— 工作区里记过一条硬教训：
> **移出 git 的路径在后续 checkout / rebase 切换提交时会被 Git 删掉工作树文件**（`.gitignore` 拦不住）。
> 要么先确保有独立物理副本，要么就别撤。
