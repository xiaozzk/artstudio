## 可用命令（官方 spine-scripts 形式）

```bash
/applications_path="/Applications/Spine.app/Contents/MacOS/Spine"
"$SPINE" -Xmx2048m --update 4.3.26 \
  --input  task/005-generic-skeleton/output/Unit_Spine_EmpirePaladinSpe1Skin1.spine \
  --output tmp/out-dir/ \
  --export json+pack
# 产出：Unit_Spine_EmpirePaladinSpe1Skin1.{json,atlas,png}
# 控制台：JSON export / Pack: ... (attachments) / Complete.
```

**⚠ 排雷（4.3 实测）**：必须带 `--update <编辑器版本>`（如 `4.3.26`，`xx` 取最新补丁亦可）。
不带时参数由旧版 launcher（4.3.05）自己解析，`--export json+pack` 快捷值不认识直接丢参，
报 `ERROR: Output specified without an input or action.`
（官方 spine-scripts 源码里每次调用也都带 `--update $VERSION`，出处：spine-scripts/export/spine-export.sh）。

其他可用形式：
- `--export` 值也可换成 `binary` / `binary+pack` / `json`，或 **`.export.json` 设置文件路径**
  （`.spine` 同目录放 `*.export.json`，首字段 `class: "export-*"`，官方脚本会自动 picks up）。
- `--set name=value` 可逐字段覆盖设置；`--clean` 动画清理；`-m` 清理并回存工程。
- `--last-export-settings` 从工程提取最近一次 GUI 导出设置（同样需要 `--update`）。

### CLI 用法排雷补充

- `--set name=value` 两个坑：① 必须写在对应 `-e/-p` **之前**（下一个 action 用设置文件）；② `-e json` 快捷值不算设置 JSON，`--set` 只能配 `-e <路径>` / `-p <路径>`。
- `nonessential` 键是官方导出设置键（`spine-runtimes/examples/export/json.json` 背书），CLI 帮助文本与网页文档均未列 schema；对本工程开关无效果（无此类数据可增）。
