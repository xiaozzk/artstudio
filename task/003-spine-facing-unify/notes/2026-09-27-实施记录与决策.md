## 3. 验收闸门实现口径（对调研 §7 的落地）

- **G1 双翻恒等**：对烘焙产物再烘焙一次，与原包做归一化递归 diff
  （int/float 等价、显式缺省值与缺省字段等价、−0.0≡0）。θr=0 包逐位精确；θr≠0 包
  （K 共轭涉及 ±2θr 的浮点往返）允许 ≤1e-9 数值残差并在报告中给出 max diff。
- **G2 运行时等价**：按官方 spine-ts **4.3** `BonePose.updateWorldTransform`（含 Normal /
  OnlyTranslation / NoRotationOrReflection / NoScale / NoScaleOrReflection 五分支与 skeleton.scaleX 传播）
  与 `Animation` 各 timeline 在 alpha=1 / from=setup 的 apply 语义（rotate/translate/shear 相对 setup 偏移、
  scale 为 setup 乘数、线性/stepped 插值、首 key 前取 setup）实现数值模拟器。
  **口径 A（闸门）**：root 动画通道固定 setup → 「原包+scaleX=−1」vs「烘焙包+scaleX=+1」逐骨
  (a,b,c,d,worldX,worldY) max diff ≤ 1e-6，采样 = 每动画全部关键帧时刻 ∪ {0, duration}。
  **口径 B（信息级）**：含 root 动画的全量模拟，报告记录 max diff（预期非零，属 D4 边界），不作闸门。
- **G3 不动项审计**：递归 diff 原包 vs 产物，仅允许差异落在
  ①root 直接子骨(inherit=normal) 的 x/rotation/shearX/shearY/scaleX 五字段
  ②这些骨的动画 rotate.value / translate.x,y / shear.x,y 通道值（scale 通道不变）
  ③（Tier 2 B-a 包）排除域可见附件的 x/rotation/scaleX、mesh 顶点 x、triangles 绕向、deform 顶点 x。
  slots/skins 其余字段/skeleton 块/事件/drawOrder 一律不得变；atlas/png 不写入（仅 JSON 产物）。
- **G4/G5**（视觉 / player）：按用户要求**留待人工校验**，本批不自动执行；产物与报告备检。

## 3.5 实施期重大实测修正（2026-09-27，全库复扫 + 工具试跑）

1. **constraints 实为 68/107 包**（ik 263 / transform 207 / path 32）——调研"0/107"结论系扫描脚本
   误判（constraints 为 list 布局被漏检）。**修正决策：不再防御性拒绝**。共轭烘焙不动 constraint 参数；
   等价性靠「基础世界矩阵匹配（G2）+ 参数未动（G3）⇒ runtime 重解一致」保证，视觉由人工 G5 兜底。
2. **noScale 骨的镜像陷阱（调研 §4.3 口径修正）**：4.3 runtime 的 noScale 分支带符号修正——
   父骨世界含反射（被镜像）而 skeleton 未翻时会把本骨**去镜像**。镜像子树内的 noScale 骨
   无法靠共轭正确镜像。**修正决策：将镜像子树内的 noScale 骨改写为 normal**
   （原包渲染不变的充要条件 = 父骨世界 |scale|≈1 且无反射，逐动画关键帧数值验证，不满足则拒绝）。
3. **G2 参考系修正为「真镜像」**：烘焙包逐骨世界 == Fx·(原包+1 世界)。原口径（runtime-flip 参考）
   对 noScale 骨本身就有去镜像偏差，新口径更严格且直指"人物完全换向"语义。root 与排除域不参与比较。
4. **translate key 必须成对写回 x/y**：θr≠0 时 y'=K[3]·x 不可丢，否则双翻失逆（G1 抓到 1e-6 残差）。
5. **翻转域 = root 直接子骨 inherit∈{normal,noScale}**（调研 §4.2 只写 normal 是笔误，§4.3 明确
   noScale 参与翻转）。
6. **试跑全库：91/107 包三闸门全过；16 包拒绝**——拒绝原因均为 noScale 骨改写不安全
   （父骨世界 |scale|≠1 或已含反射 det<0，改写会改变原包渲染）：Pest、火把女战士、Kimchul、
   player、kunai_ninja、CatGirl、electro-archer、bbaksang、Tattooist、gonbong、yunggul、
   Act3_Polearm_GuardL、_replaced_leega、leega、bboy、哪吒童。
   这 16 包在报告中逐包记录原因，**留待人工/专项**（候选：逐包定制矩阵烘焙或旧式全量翻转，另行决策）。
