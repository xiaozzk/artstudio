## 4. 算法规格（方案 A：共轭烘焙）

### 4.1 数学核心

设 Fx = diag(−1,1)（跨竖直轴的世界镜像）。Spine 骨骼局部矩阵
`L = T(x,y)·A(rotation, shearX, shearY, scaleX, scaleY)`（A 的两列 = `u(rotation+shearX)·scaleX` 与
`u(rotation+90+shearY)·scaleY`，与 runtime `Bone.updateWorldTransformWith` 完全一致）。

**恒等式**（本库 root 旋转 ≈0 时精确）：

```
L(−x, −rot, −shx, −shy, −kx, ky) == Fx · L(x, rot, shx, shy, kx, ky)
```

推论：

1. **只需共轭 root 的直接子骨**：root 不动（世界系不变），直接子骨局部取 `L' = Fx·L` 后，
   其世界 `W' = root·L' = Fx·W`；再往下的孙子骨局部**原样不动**，世界自动 `= Fx·(原世界)`
   （矩阵乘法结合律：`Fx·W_child = Fx·W_parent·L_grand = W'_parent·L_child`）。
   **把所有骨头全部取反是错的**：`Fx·L1·Fx·L2 ≠ Fx·(L1·L2)`，嵌套两层起就会错。
2. **运行时严格等价**：烘焙包以 skeleton.scaleX=+1 运行 == 原包以 skeleton.scaleX=−1 运行，
   逐骨（含全部 inherit 分支、constraint 后续计算）成立——因为两者的父骨世界矩阵逐骨相同，
   runtime 一切下游逻辑（inherit 特殊分支、IK、物理）都在相同世界上计算。
3. **附件/atlas 零改动**：附件世界 = 骨世界·附件局部；骨世界已被镜像 → 附件局部原样即得镜像渲染。
   不翻贴图、不翻 mesh 顶点、不动 UV/triangles/deform——**产物与原包共用同一 atlas/png**。

### 4.2 修改清单（Tier 1 包，逐包）

**bones 数组**：只改 root 的直接子骨（parent == root.name 且 `inherit` 为 normal）：

| 字段 | 变换 |
|------|------|
| `x` | 取负 |
| `y` | 不变 |
| `rotation` | 取负 |
| `shearX` | 取负 |
| `shearY` | 取负 |
| `scaleX` | 取负 |
| `scaleY` / `length` / `inherit` / `skin` / `color` / `name` / `parent` | 不变 |

**animations**：只改上述骨骼的同名时间线通道：

| 通道 | 变换 | 依据（4.2/4.3 runtime 语义） |
|------|------|------------------------------|
| `rotate`（key 字段 `value`） | `value → −value` | key 是相对 setup 的偏移（`bone.rotation = data.rotation + value·alpha`） |
| `translate`（`x`,`y`） | `x → −x`，`y` 不变 | 同上（`bone.x = bone.data.x + x·alpha`） |
| `translatex` / `translatey` | 各自分量的同规则 | 单轴通道同语义 |
| `scale`（`x`,`y`） | **不变** | runtime：`x *= bone.data.scaleX` 后 `bone.scaleX = x`——key 是 setup scale 的**相对乘数**，镜像符号由 setup 的 −scaleX 提供 |
| `scalex` / `scaley` | 不变 | 同上 |
| `shear`（`x`,`y`） | `x → −x`，`y → −y` | key 是 setup 偏移 |
| `shearx` / `sheary` | 各自分量的同规则 | 单轴通道 |
| `curve` | `linear` 缺省与 `"stepped"` 不动；若出现 bezier 数组（本库实测 0 个），按各通道 `v' = s·v + c`（s∈{±1}，c 为该通道偏移）变换 value 分量（数组下标 1、3，每 4 个一组）并告警 | 见 §3 curve 统计 |

**一切不动**：root 骨自身、非直接子骨、`inherit ≠ normal` 的直接子骨及其整棵子树（§4.3）、
slots、skins（附件全字段）、events、drawOrder、skeleton 块、atlas、png。

### 4.3 翻转域与"排除域"语义

runtime `Bone.updateWorldTransformWith` 的 inherit 分支（源码实证）：

- `normal`：完整继承父变换（含**反射**）→ 参与翻转；
- `noScale`：继承旋转+**反射**、不继承 scale（分支里专门有保号修正）→ **参与翻转**（本库 936 骨）；
- `onlyTranslation` / `noRotationOrReflection` / `noScaleOrReflection`：**不继承反射** → **不参与翻转**
  （局部数据原样，其世界系与原包同样地"不镜像"）。

排除域骨头与其子树**数据原样保留**，这正是与 runtime root scaleX=−1 等价的行为。
后果见 §6 Tier 2。

### 4.4 精确性残差（显式声明）

- root rotation ≠ 0 的 6 包（|θr| ≤ 0.185°）：纯取反与真共轭差一个 ≤ 2θr（≤ 0.37°）的旋转残差，
  位置误差 ~0.6% 量级。**接受**（统一朝向的语义目标不受影响）；如需绝对精确，
  对这 6 包的 translate key 用 K·(x,y) 精确共轭（实现可选）。
- root 动画被 key rotate 的 26 包：烘焙包的镜像轴**固定在 setup 帧**，
  root 的动画旋转不随镜像翻转（见 §8 风险表）。

## 5. 方案 B（Tier 2：排除域骨头挂可见附件的 20 包）

共轭烘焙对这 20 包会把"排除域"的美术留在原朝向（与 runtime root-flip 语义一致，
但**人物没有完整换向**——例如 zhangzitong 57/59 个可见附件在排除域）。
处理策略为**决策点 D2**，候选：

- **B-a 排除域附件二次翻转（推荐先试）**：在方案 A 基础上，对排除域骨头的可见附件做"旧式翻转"
  （region：x/rotation 取负 + scaleX 取负；mesh：顶点 x 取负 + triangles 反绕；linkedmesh 跟随；
  对应 deform 动画顶点 x 取负）。精确性条件 = 该骨世界系线性部分在整条动画中恒定（无 rotate/scale key）。
  **数值判定规则**：逐帧模拟该骨世界矩阵，若线性部分变化幅度 > 阈值（建议 0.5°）→ 该包该附件不可精确翻转，
  降级到 B-b 或人工评估。
- **B-b 整包退回旧式全量翻转**：对整包用 `spine_flip.py` 口径（全局部取反 + 附件贴图翻转）。
  本库零 constraints → 可直接跑；缺点：与"真镜像"有嵌套共轭偏差（002 v2 实测视觉可接受），
  且 Tier 2 包的数据手性与 Tier 1 产物**不一致**（迁移时这两包仍需注意）。
- **B-c 逐包混合 + 看图验收**：同一包内 body 走 A、排除域走 B-a 判定通过的附件走二次翻转、
  判定不过的保持原样并记录——最终以 render 对比 + player 播放为准。

无论哪种策略，Tier 2 包必须**逐包**过 §7 的视觉闸门 + player 闸门，并在报告里记录所选策略。

## 6. 朝向判定流程（沿用 002 阶段 0.5）

1. 每包渲染 setup 帧（`tools/spine/anim/render_rig.py`），agent 看复原预览图判定当前朝向（left/right）；
   `detect_facing` 眼骨启发式仅作参考（非全库覆盖）。
2. 统一目标朝向由用户拍板（决策点 D1；002 的 A/B 模板包均朝左，建议对齐）。
3. `--from <当前> --to <目标>` 成对声明：相同 → 原样输出（照常进产物集），不同 → 烘焙一次。
   ⚠ 已烘焙副本不得再次当原包输入（002 法袍法师踩过双翻回原样）；
   报告与产物目录须记录"已烘焙"标记，`Act3_Polearm_GuardL.json`（root scaleX=−1）的声明以看图为准。

## 9. 风险与已知边界

- **root 动画旋转（26 包）**：烘焙包中 root 自身的动画旋转不镜像（旋转值原样保留）；
  视觉表现为镜像轴固定、root 摆动方向不换。数据手性统一的目标不受影响；player 闸门兜底。
- **scale mixIn 瞬态**：runtime `ScaleTimeline` 在 alpha<1 的 mixIn/setup 分支用 `|x|·signum(...)`
  做符号过渡，烘焙包（setup 取负、key 不变）在**动画交叉淡化瞬间**的 scale 符号过渡
  可能与 runtime-flip 有细微差异；单动画完整播放（alpha=1）严格精确。G2 的采样若含混合场景需放宽该帧。
- **眼骨朝向启发式**非全库覆盖（002 实测仅部分包有眼骨）——朝向判定以看图为准。
- **防御性退出**：实施工具遇到 constraints / 未知附件类型 / 未知 inherit 值 / 非 4.3 格式 → 报错退出，
  不静默产出（沿用 002 的工具纪律）。
- **JSON 重写格式**：产物用紧凑 JSON（separators=(",", ":")），与 002 交付包口径一致；
  键序保持解析序，不新增任何字段（hash 字段随原样保留，报告中注明"hash 不再匹配原包"属预期）。
